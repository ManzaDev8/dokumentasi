PENTING
Jangan pakai versi Play Store

Versi Termux di Google Play Store sudah usang dan tidak lagi diperbarui. Selalu gunakan F-Droid atau GitHub Releases.

Setup Awal

// 4 langkah
1
Update & Upgrade
Jalankan pkg update && pkg upgrade -y untuk memperbarui repositori dan paket.
2
Izinkan Akses Storage
Jalankan termux-setup-storage lalu tap Allow. Ini memberi akses ke folder Download, DCIM, dll.
3
Install Paket Esensial
pkg install git wget curl python proot-distro -y
4
Perbaiki Mirror (jika lambat)
Jika download lambat, jalankan termux-change-repo dan pilih mirror yang lebih dekat.
termux — setup lengkap
# update repositori pkg update && pkg upgrade -y # akses storage termux-setup-storage # paket dasar pkg install git wget curl nano -y # bahasa pemrograman pkg install python nodejs -y # proot-distro untuk Linux pkg install proot-distro -y # ganti mirror jika lambat termux-change-repo

Install Kali Linux

// proot-distro
1
Install proot-distro
pkg install proot-distro -y
2
Install Kali
proot-distro install kali
3
Login ke Kali
proot-distro login kali
4
Update di dalam Kali
apt update && apt upgrade -y
5
Install desktop (opsional)
apt install kali-desktop-xfce -y lalu jalankan startxfce4 lewat Termux:X11.
termux — kali linux
# install proot-distro pkg install proot-distro -y # install kali rolling proot-distro install kali # login ke kali proot-distro login kali # di dalam kali: update apt update && apt upgrade -y # install desktop xfce4 apt install kali-desktop-xfce -y # keluar exit

Section 05 — Tutorial

Tutorial Dasar.

Panduan langkah demi langkah untuk pemula. Dari install sampai pakai harian.

Alur Belajar

// roadmap
1
Install F-Droid & Termux
Download F-Droid dari situs resmi, install, lalu cari "Termux" di dalam F-Droid dan install.
2
Setup Awal
Update paket, izinkan storage, install tools dasar. Detail di halaman Termux.
3
Pelajari Command Dasar
Kuasai ls, cd, cp, mv, rm, dan nano.
4
Install Bahasa Pemrograman
pkg install python nodejs -y lalu coba tulis script sederhana.
5
Coba Linux via proot-distro
Install Kali atau Ubuntu dengan proot-distro, lalu eksplor command Linux di dalamnya.
6
Eksplor GUI (Opsional)
Install Termux:X11 dan desktop environment untuk pengalaman Linux grafis di HP.

Tips Pemula

// biar lancar
💡
TIP 01
Jangan pakai Play Store

Versi Play Store usang. Selalu pakai F-Droid atau GitHub.

🔋
TIP 02
Matikan battery optimization

Agar Termux tidak dimatikan paksa oleh Android saat berjalan di background.

📶
TIP 03
Ganti mirror jika lambat

Jalankan termux-change-repo dan pilih mirror terdekat.

💾
TIP 04
Siapkan storage

Linux di proot butuh ruang. Sisakan minimal 2-3 GB kosong.

🔐
TIP 05
Aktifkan password

Untuk Kali, ganti password default kali dengan passwd.

📚
TIP 06
Baca dokumentasi resmi

Selalu cek dokumentasi resmi sebelum mengikuti tutorial pihak ketiga.
